# Roll Call Documentation

This folder is organized around one rule: current implementation and current product decisions win over older plans.

## Current project truth

- [Where We Stand](./WHERE_WE_STAND.md) — concise status, known limitations, and immediate verification priorities.
- [Decisions](./DECISIONS.md) — append-only record of approved, reversed, and superseded decisions.
- [Working Changelog](./WORKING_CHANGELOG.md) — internal source material for future public release notes.

## Product reference

- [North Star](./product/NORTH_STAR.md) — the shortest statement of product purpose and non-negotiables.
- [Application Overview](./product/APP_OVERVIEW.md) — current user flows, vocabulary, screens, and behavior.
- [Product Scope](./product/PRODUCT_SCOPE.md) — durable boundaries, support rules, and exclusions.
- [UX Rulebook](./product/UX_RULEBOOK.md) — current interaction and live-use rules.
- [Readiness Model](./product/READINESS_MODEL.md) — the meaning of player and team readiness.
- [Appearance Rules](./product/APPEARANCE_RULES.md) — Light/Dark and live-screen behavior.
- [Architecture Guardrails](./product/ARCHITECTURE_GUARDRAILS.md) — data, ownership, sharing, and reliability constraints.
- [Product Opportunities](./product/PRODUCT_OPPORTUNITIES.md) — exploratory future ideas; not a committed roadmap.
- [Public Changelog](./product/PUBLIC_CHANGELOG.md) — human-curated public release notes.

## Development reference

- [Build Environments](./development/BUILD_ENVIRONMENTS.md) — Debug, Internal, and Release schemes and archive checks.

## Historical archive

- [Historical Archive](./historical/README.md) — condensed records of earlier plans, redesign work, implementation handoffs, and support design.

Historical documents explain how the current product direction was reached. They are not standalone authorization to change the app. The current implementation, current product docs, and decision log remain the sources of truth.
