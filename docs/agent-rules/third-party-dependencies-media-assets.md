# Third-Party Dependencies, Media, and Asset Rules

Read this file when the task touches Third-Party dependencies, media and assets.

- Before adding any third-party dependency, explain: what problem it solves, why native APIs are insufficient, the dependency license, whether it is safe for commercial/App Store distribution, whether attribution is required, and whether modifications require source disclosure
- Prefer: MIT, Apache 2.0, BSD, and public-domain/CC0 assets

- Never scrape random sounds, images, fonts, or media from the internet.
- Any bundled media must have clear redistribution rights, a documented source, a documented license, and attribution requirements tracked

- Keep a machine-readable ATTRIBUTIONS.md file listing asset/library name, source URL, license, and attribution requirements

- About/Licenses screens should automatically surface required attributions where practical.
