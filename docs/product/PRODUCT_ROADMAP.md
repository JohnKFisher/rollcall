# Roll Call Product Roadmap

## 1.0

Roll Call 1.0 should ship as a complete free app focused on Game Day.

Must include:
- Basic Onboarding process
- Team Home
- √ Game Day
- √ Multiple teams
- √ Players
- √ Optional player numbers
- √ Player photos
- Team identity: name, colors, logo
- Adjustments to Auto-fade
- √ Apple Music playback
- Local/imported audio
- √ Intro + song chaining
- √ Cue points
- √ Manual sharing/import/export
- √ Backup/restore
- √ Fallback audio so Game Day never fails
- UI Consistency pass
- √ No required account
- √ No ads
- √ No premium paywall in 1.0

## 1.x / Later

Explore after launch:
- Improved Clips
- Proper Onboarding process
- Improved Readiness
- Improved Backup/Restore
- Improved Photo Editing
- Recovery / Recently Deleted
- Archive, only if team clutter becomes real
- Ongoing Presentation polish
- Better sharing convenience
- Improved song selection process
- Improved clip creation process
- Rating Request
- Improved Launch Screen

## Future Plus Candidates

Strong candidates:
- Presentation styles
- Game Day styles
- Announcer Studio
- Batch editing
- Easier sharing
- Save Apple Music clip as local file

Possible candidates:
- Playlist creation from Team Songs.
- Multiple intro presets
- Multiple song presets
- Advanced templates
- Premium presentation packs
- Cloud sync


Weak / not currently compelling:
- Analytics/history
- Remote control
- Audio engineering tools

## Explicit Non-Goals

Do not build:
- Social features
- Public profiles
- Ads
- Required accounts
- Required cloud
- Sports management / stats platform
- Event production software
