# Roll Call Product Roadmap

## 1.0 Submitted

Roll Call 1.0 has been submitted to the App Store as a complete free app focused on Game Day.

Included:
- √ Basic Onboarding process
- √ Game Day
- √ Multiple teams
- √ Players
- √ Optional player numbers
- √ Player photos
- √ Team identity: name, colors
- √ Adjustments to Auto-fade
- √ Apple Music playback
- √ Local/imported audio
- √ Intro + song chaining
- √ Cue points
- √ Manual sharing/import/export
- √ Backup/restore
- √ Fallback audio so Game Day never fails
- √ UI Consistency pass
- √ No required account
- √ No ads
- √ No premium paywall in 1.0

## Future Plus Candidates

Strong candidates:
- Presentation styles
- Game Day styles
- Announcer Studio
- Batch editing
- Easier sharing
- Save Apple Music clip as local file
- Lyric based song selection?

Possible candidates:
- Playlist creation from Team Songs.
- Multiple intro presets
- Multiple song presets
- Advanced templates
- Premium presentation packs
- Cloud sync


Weak / not currently compelling:
- Analytics/history
- Remote control
- Audio engineering tools

## Explicit Non-Goals

Do not build:
- Social features
- Public profiles
- Ads
- Required accounts
- Required cloud
- Sports management / stats platform
- Event production software
